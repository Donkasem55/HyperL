# HyperL: A reasonable successor to L#.

Personally, I'd consider the codebase of L#, absolutely screwed. Therefore, I'm creating a new language with L#'s design philosophy, and reasonably this time. There's also no misleading names. No #, it's not .NET. It's going to compile to Assembly just like L# was.
